# Tacet

Десктопный музыкальный плеер для Windows: библиотека, плейлисты, тексты песен,
эквалайзер и Discord Rich Presence.

**[Скачать последнюю версию](https://github.com/xVerdy1337/Tacet-releases/releases/latest)**

Скачайте файл `Tacet-Setup-<версия>-x64.exe` из релиза и запустите установщик.
Node.js не требуется. При обновлении библиотека и настройки сохраняются.

Начиная с 0.3.2 новые версии доступны в **Настройки → Приложение → Обновления**.
Приложение может проверять обновления автоматически; скачивание и установка
начинаются только по нажатию. Для 0.3.1 и более ранних версий первое обновление
нужно установить вручную.

Этот репозиторий содержит официальные установщики, контрольные суммы и файлы
обновления. Исходный проект хранится отдельно.
